# Моушн-бриф — Ledgerly

Для шотов S04 и S06, push-уведомления в S03 и всех титров. Значения взяты из `brand.json → motion` и `film`, то есть **это те же кривые и длительности, что на сайте**.

## Характер
`precise`: **точно, коротко, без пружин.** Три слова: *прочерчивается, досчитывается, ложится.*

| Токен | Значение | Где |
|---|---|---|
| duration-fast | 120ms | смена статуса «ждём → оплачен», появление точки статуса |
| duration-base | 200ms | появление титра (opacity), строки таблицы |
| duration-slow | 360ms | прочерчивание линейки (scaleX 0→1), маркер под суммой |
| ease-standard | cubic-bezier(.2,0,0,1) | линейки, маркер |
| ease-enter | cubic-bezier(0,0,0,1) | вход титров и строк (translateY 8px → 0) |
| ease-exit | cubic-bezier(.4,0,1,1) | уход элементов (только opacity) |
| досчёт цифры | ≤ 600ms, ease-out cubic | «Ваше: 184 240 ₽» |

**Что двигается:** линейки, маркер, строки «листа», цифры, титры.
**Что не двигается никогда:** форма словесного знака, бумажный фон, цвета бренда. Без поворотов, масштабирования логотипа, отскоков и глитчей.

## Логотип в движении (бампер / заставки)
Сборка: знак opacity 200ms → линейка под «ly» 360ms → держим 1000ms → уход opacity 200ms. Итого 1,76 с (≤ 2 с).

## Титры
Literata 600, 64–72px при 1080 ширине, межстрочный 1.08, трекинг −0.015em, чернила на бумаге / бумага `#EDE9DF` на ночи (S05). Под титром короткая линейка 1px шириной в 40% строки, прочерчивается за 360ms после появления титра (opacity 200ms). Безопасная зона: 14–80% по высоте, 64px слева, не правее 85% ширины.
