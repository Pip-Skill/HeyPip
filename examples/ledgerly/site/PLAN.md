# План лендинга — Ledgerly

**Главное действие:** «Попробовать бесплатно» (регистрация по e-mail, [N] дней, без карты).
Появляется: в шапке (всегда видна), в герое, после тарифа, в финальной форме. Все остальные кнопки — secondary/ghost.

**Источник трафика:** Reels → 80% мобильных. Первый экран на 390px: заголовок + подзаголовок + кнопка видны без прокрутки, «лист» продукта — сразу под ними.

## Секции

| # | Секция | Задача | Заголовок | Что показано |
|---|---|---|---|---|
| 1 | Шапка | ориентир + действие | — | словесный знак, 3 ссылки, переключатель темы, «Войти», «Попробовать бесплатно» |

## Поток регистрации и состояния формы
вход (Reels/шапка) → герой → кнопка → якорь к форме (#start) → e-mail → «Отправить» →
- **пусто/неверный формат:** «Похоже, в адресе опечатка. Проверьте, пожалуйста.» (кирпичный текст + иконка, `aria-invalid`, фокус в поле)
- **отправка:** кнопка «Отправляем…», `aria-busy`, повторный клик заблокирован
- **успех:** «Письмо ушло на {email}. Откройте его — там ссылка для входа.»
- **ошибка сети:** «Не получилось отправить. Попробуйте ещё раз через минуту.» (в прототипе не эмулируется, текст подготовлен)

## Композиция (чтобы не выглядело шаблоном)
split-герой → «записки» в сетке 2×2 → плотная таблица шагов → full-bleed фото → ведомость → два плейсхолдера → один крупный лист-тариф → аккордеон → форма на отдельном «листе» с двойной линейкой.
