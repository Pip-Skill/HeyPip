# Шот-лист — Ledgerly «Чистовик»

Серия может быть сгенерирована (см. `prompts.md`) или снята за полдня в одной квартире-студии. Шот-лист рассчитан на реальную съёмку и задаёт порядок для генерации.

**Цель:** 4 кадра одной серии для лендинга и запуска в соцсетях + первый кадр для Reels.
**Локация:** квартира-студия с высоким окном на восток/юго-восток, деревянный стол, светлая штукатурка.
**Команда:** фотограф, ассистент по свету, фуд/предметный стилист (бумага, «беспорядок»), 1 модель рук (иллюстратор(ка) 28–38).
**Сдача:** 4 финальных кадра × все форматы из style-guide, плюс 10–15 альтернатив, 3 рабочих дня после съёмки.
