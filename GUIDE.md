# Pip — обучалка для новичка

## Что такое Pip

Pip — это дизайн-студия внутри Claude: вы пишете одну фразу вроде «сделай бренд и сайт для моей кофейни», и Claude проходит весь путь студии — от идеи до готовых файлов. Главная фишка: всё строится из одного файла бренда `brand.json`, поэтому сайт, плакаты, фото и видео выглядят как один бренд.

Что он умеет:

- **Бренд:** позиционирование, стиль, мудборд, цвета, шрифты, брендбук.
- **Логотип:** 4 направления в SVG — надпись, монограмма, знак + надпись, значок.
- **Сайты и лендинги:** через встроенный движок design-taste, с настоящими шрифтами и проверкой на 4 размерах экрана.
- **Печать и соцсети:** плакаты A2–A6 и 50×70, флаеры, визитки, посты и сторис Instagram — PDF для типографии и PNG.
- **Фото:** стайлгайд съёмки и промпты для Midjourney, Flux, SDXL.
- **Видео:** сценарий, раскадровка и промпты для Kling, Runway, Luma, Veo.
- **Код:** 9 агентов-помощников (ревью, тесты, безопасность) и 15 команд разработчика.

Внутри — база дизайна на 89 стилей, 192 палитры и 74 пары шрифтов, поэтому решения опираются на данные, а не на вкус наугад.

## Установка

Есть два способа. В Claude Code — всё, включая 28 команд и агентов; в обычном Claude (сайт и приложение) — сам скилл, без команд и агентов.

| | Claude Code (плагин) | Claude на сайте и в приложении (скилл) |
| --- | --- | --- |
| Файл | `heypip-plugin.zip` | `heypip.skill` |
| Команды `/heypip:…` | да, 28 | нет — просто пишите словами |
| Агенты и хуки | да | нет |
| Движок сайтов | да | нет (сайты по встроенным правилам) |
| Кому | если вы уже в терминале или делаете сайты | если никогда не открывали терминал |

### В Claude Code

1. Распакуйте `heypip-plugin.zip` — получится папка `heypip-plugin`.
2. Запустите Claude Code и введите: `/plugin marketplace add /путь/к/heypip-plugin` (путь можно перетащить мышкой в окно терминала).
3. Затем: `/plugin install heypip@heypip` и перезапустите Claude Code.
4. Проверка: введите `/heypip:help` — должна появиться шпаргалка.

Когда репозиторий лежит на GitHub, шаг 2 короче: `/plugin marketplace add Pip-Skill/HeyPip`. Для сайтов нужны Node 22+ и Chrome, для скриптов — Python 3.9+.

### В Claude на сайте или в приложении

1. Включите выполнение кода: «Настройки → Capabilities», переключатель «Code execution and file creation» (в новом интерфейсе — «Create and edit files»). Без него скиллы не работают.
2. Откройте «Customize → Skills», нажмите «+», затем «+ Create skill» → «Upload a skill».
3. Выберите `heypip.skill`. Это версия без движка сайтов (claude.ai принимает не больше 200 файлов в скилле); сайты она делает по встроенным правилам, всё остальное на месте.
4. Убедитесь, что переключатель у Pip включён.

Скилл, добавленный на сайте, виден только вам и подтягивается в Claude Code, если войти тем же аккаунтом. Источник: [справка Claude про скиллы](https://support.claude.com/en/articles/12512180-getting-started-with-skills-on-claude-ai).

## Первый проект за 10 минут

Начните с `/heypip:start` — Pip сам задаст три простых вопроса и сделает остальное. В обычном Claude напишите словами: «Используй Pip: …».

1. **Скажите, что делаем.** Например: `/heypip:start бренд и сайт для кофейни в Берлине, жарим зерно сами`.
2. **Ответьте на 1–2 вопроса:** для кого это и на каком языке тексты. Про цвета и шрифты думать не нужно.
3. **Выберите одно из трёх направлений.** Pip покажет три варианта: стиль, цвета, шрифты и почему. Можно сказать «второй, но теплее».
4. **Подождите 5–15 минут.** Появится папка проекта: брендбук, мудборд, файл цветов и шрифтов, сайт.
5. **Откройте результат.** Дважды щёлкните `brandbook.html` или `site/index.html` — откроется в браузере.
6. **Правьте словами.** «Сделай акцент темнее», «заголовок короче», «добавь секцию с меню».
7. **Продолжайте в том же стиле.** `/heypip:poster афиша дегустации в субботу, A3 + пост + сторис` — плакаты подхватят бренд сами.

Хороший запрос всегда отвечает на три вопроса: **что это, для кого и чем отличается.** «Кофейня» даст средний результат; «кофейня-обжарка для соседей по району, 12 мест, жарим по средам прямо в зале» — сильный.

## Все команды

Команды работают в Claude Code. В обычном Claude то же самое делается словами: «Pip, сделай плакат …».

### Дизайн

| Команда | Что делает | Пример |
| --- | --- | --- |
| `/heypip:start` | ведёт по шагам, для первого раза | `/heypip:start` |
| `/heypip:help` | шпаргалка по всем командам | `/heypip:help` |
| `/heypip:brand` | бренд целиком: направление, мудборд, цвета, шрифты, брендбук | `/heypip:brand йога-студия для новичков в Мюнхене` |
| `/heypip:moodboard` | 2–3 визуальных направления на выбор | `/heypip:moodboard семейная пекарня, тепло и детство` |
| `/heypip:system` | дизайн-система и токены для кода | `/heypip:system наши цвета #0F172A и #22D3EE` |
| `/heypip:logo` | 4 варианта логотипа в SVG | `/heypip:logo «Рёст», обжарка кофе` |
| `/heypip:site` | сайт или лендинг | `/heypip:site лендинг для записи на пробное занятие` |
| `/heypip:poster` | плакаты, флаеры, визитки, посты, сторис | `/heypip:poster открытие 14 марта, A2 + пост + сторис` |
| `/heypip:photo` | стиль съёмки и промпты для Midjourney / Flux | `/heypip:photo 6 кадров для сайта, Midjourney` |
| `/heypip:video` | сценарий, раскадровка, промпты для Kling / Runway / Veo | `/heypip:video Reels 15 секунд, Kling` |
| `/heypip:campaign` | всё сразу в одном стиле | `/heypip:campaign запуск приложения для репетиторов` |
| `/heypip:review` | разбор и исправление готовой работы | `/heypip:review ./my-site` |
| `/heypip:find` | поиск по базе дизайна | `/heypip:find type luxury editorial` |

### Код

| Команда | Что делает |
| --- | --- |
| `/heypip:plan` | план реализации перед стартом |
| `/heypip:tdd` | сначала тесты, потом код |
| `/heypip:code-review` | ревью изменений на качество и безопасность |
| `/heypip:e2e` | тесты сайта в браузере (Playwright) |
| `/heypip:verify` | полная проверка: сборка, типы, линтер, тесты |
| `/heypip:build-fix` | чинит ошибки сборки по одной |
| `/heypip:test-coverage` | ищет непокрытый код и пишет тесты |
| `/heypip:refactor-clean` | убирает мёртвый код |
| `/heypip:checkpoint` | сохраняет точку прогресса |
| `/heypip:eval` | разработка через проверки (evals) |
| `/heypip:learn` | вытаскивает из сессии полезные приёмы |
| `/heypip:orchestrate` | цепочка агентов для сложной задачи |
| `/heypip:update-docs` | обновляет документацию |
| `/heypip:update-codemaps` | обновляет карту архитектуры |
| `/heypip:setup-pm` | выбор менеджера пакетов (npm, pnpm, yarn, bun) |

Агентов вызывать не нужно: Pip и команды зовут их сами. Можно и напрямую: «пусть security-reviewer проверит форму записи».

## Как устроен проект

Всё для одного бренда лежит в одной папке, а её сердце — файл `brand.json`: цвета, шрифты, отступы, анимации, правила для фото и видео. Всё остальное строится из него.

```
моя-кофейня/
├── brief.md          ← бриф и допущения
├── direction.md      ← направление и позиционирование
├── moodboard.html    ← мудборд (открыть в браузере)
├── brand.json        ← ИСТОЧНИК ПРАВДЫ
├── tokens/           ← цвета и шрифты для кода (создаются сами)
├── brandbook.html    ← брендбук (создаётся сам)
├── logo/             ← логотипы SVG + лист logos.html
├── site/             ← сайт, index.html + шрифты внутри
├── print/            ← плакаты, флаеры, посты: PDF + PNG
├── photo/            ← стиль съёмки и промпты
├── video/            ← сценарий, раскадровка, промпты
└── review.md         ← что проверено и исправлено
```

**Как менять.** Не правьте сайт или плакат руками, если меняется стиль. Скажите: «поменяй акцентный цвет на тёмно-зелёный и перегенерируй всё». Pip поменяет `brand.json`, проверит читаемость и обновит токены, брендбук, сайт и плакаты разом. Тексты и мелкие детали можно править напрямую — просто просите словами.

## Рецепты

Готовые запросы — копируйте и меняйте под себя.

**Бренд с нуля.** `/heypip:brand студия растяжки для офисных работников 30–45 лет, занятия по 40 минут в обед, не фитнес-глянец, тексты на немецком` → 3 направления на выбор, потом брендбук, мудборд, `brand.json`.

**Сайт.** `/heypip:site одностраничник: расписание, цены, запись на пробное занятие` → `site/index.html`, проверенный на телефоне и компьютере. Чтобы выложить в интернет бесплатно, перетащите папку `site` на Netlify Drop или залейте на GitHub Pages.

**Плакаты и соцсети.** `/heypip:poster день открытых дверей 22 марта, вход свободный: плакат A2, флаер A5, пост и сторис` → PDF для типографии (с вылетами 3 мм) и PNG для соцсетей. Форматы: A2–A6, 50×70, флаер DL, визитка, пост 4:5, квадрат, сторис, превью ссылки, обложка YouTube.

**Фото через нейросеть.** `/heypip:photo 5 кадров для сайта и соцсетей, Midjourney и Flux` → стиль съёмки и готовые промпты. Скопируйте промпт в Midjourney, скачайте картинку, пришлите её в чат и скажите «вставь в герой сайта».

**Видео.** `/heypip:video Reels 15 секунд: человек за ноутбуком распрямляет спину, Kling` → сценарий с таймингами, раскадровка и промпт на каждый кадр.

**Логотип.** `/heypip:logo «Растяжка в обед»` → 4 направления и лист проверки на светлом, тёмном и цветном фоне.

**Всё сразу.** `/heypip:campaign запуск студии растяжки в апреле` → бренд, сайт, печать, фото и видео одного стиля. После направления Pip попросит подтвердить стиль, прежде чем делать остальное.

**У меня уже есть сайт.** `/heypip:review ./мой-сайт — выглядит дешево, никто не записывается` → список проблем по важности и исправления.

## Вопросы и проблемы

| Ситуация | Что делать |
| --- | --- |
| Команды `/heypip:…` не появились | Перезапустите Claude Code; проверьте `/plugin` — Pip должен быть включён |
| В обычном Claude скилл не срабатывает | Проверьте, что включено выполнение кода и сам скилл; начните запрос со слов «Используй Pip» |
| `heypip.skill` не загружается | Проверьте, что включено выполнение кода; скачайте файл из релиза заново |
| Сайт открывается «голым», без стилей | Открывайте `index.html` из папки `site`, не перенося его отдельно: стили и шрифты лежат рядом |
| Шрифт не поддерживает русский | Pip предупредит сам; скажите «подбери шрифт с кириллицей» |
| На сайте полосатые заглушки вместо фото | Это места под ваши фото: сгенерируйте по промптам из `photo/` или пришлите свои |
| В текстах есть `[ЦЕНА]`, `[АДРЕС]` | Pip не выдумывает факты; напишите ему цены и адрес, он заменит |
| Результат слишком «средний» | Добавьте в запрос отличие и что вам не нравится; попросите «3 разных направления, одно смелое» |
| Подсказки про tmux и console.log в Claude Code | Это хуки для разработчиков, они ничего не блокируют; отключаются в `/hooks` |
| Нужен Word, PowerPoint или Figma | Скажите формат прямо; токены `tokens.dtcg.json` импортируются в Figma через плагин Tokens Studio |

**Можно ли продавать сделанное?** Да, всё, что Pip сделал для вас, — ваше. Шрифты Google Fonts бесплатны для коммерции. Для сгенерированных картинок и видео действуют правила того сервиса, где вы их делали.

**Сколько это стоит в лимитах Claude?** Бренд — недолго; сайт и кампания — самые тяжёлые. На тарифе Pro запускайте большие задачи по одной, а не всё сразу.

## Шпаргалка

- Не знаете, с чего начать → `/heypip:start`
- Забыли команду → `/heypip:help`
- Хороший запрос = что это + для кого + чем отличается + язык текстов
- Порядок для нового бизнеса: `brand` → `logo` → `site` → `poster` → `photo` → `video`
- Меняете стиль → «поменяй в brand.json и перегенерируй всё»
- Не нравится → скажите что именно («слишком строго», «хочу теплее»), а не «переделай»
- Все файлы одного бренда — в одной папке; `.html` открывается двойным щелчком в браузере
- PDF из `print/` — сразу в типографию, PNG — сразу в соцсети
