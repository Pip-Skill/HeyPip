# Changelog

## 2.0.0
- Renamed to **Pip** (`heypip`). Commands are now `/heypip:*`.
- New commands: `/heypip:start` (guided first project), `/heypip:help`, `/heypip:logo`.
- Print & social: posters, flyers, business cards, Instagram posts and stories (PDF with bleed + PNG).
- Design library (styles, palettes, font pairings, UX rules) with `suggest_brand.py` and `lookup.py`.
- Web engine for sites, self-hosted Google Fonts, engineering agents, commands and hooks.
- Beginner guide (`GUIDE.md`), new icon.
